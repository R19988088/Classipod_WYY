

## 版本说明
本版本仅在原项目基础上增加了网易云音乐接口、白噪音和定时关闭功能。其他具体功能请查看原始项目 [adeeteya/Classipod](https://github.com/adeeteya/Classipod)。

部分白噪音内容参考了 [whyiyhw/lull](https://github.com/whyiyhw/lull)。
