# 白噪音模式设计

## 目标

在现有 Classipod 播放器中增加独立的白噪音模式。该模式沿用现有菜单、
GoRouter、Riverpod、播放控制和 Hero 翻转结构，不引入新的播放器依赖。

合成声音表现为最长两小时的音频，但不得生成、保存或缓存完整的两小时 PCM
文件。播放器读取到哪里，算法就实时计算到哪里。

## 主菜单

网易云音源下的相关顺序为：

1. 专辑
2. 歌单
3. 播客
4. 推荐
5. 白噪音
6. 设置

本地音源不显示播客和推荐，白噪音仍位于设置上方。

## 类型列表

白噪音页面使用现有列表页面结构，只显示以下八个类型，不显示类型内部的
声音选择器：

| 类型 | 播放候选 |
| --- | --- |
| 噪音 | 白噪音 |
| 雨 | 小雨、大雨、雷雨 |
| 水 | 海浪、溪流、瀑布 |
| 林 | 森林、鸟鸣、虫鸣 |
| 风 | 微风、大风、落雪 |
| 室内 | 风扇、空调、火车、地铁、翻书、滴答 |
| 暖 | 篝火、咖啡馆、猫呼噜 |
| 冥想 | 颂钵、低鸣 |

选择“噪音”时始终使用白噪音。选择其他类型时，在该行候选范围内随机选择
一个声音并立即播放。用户不选择具体声音。

## 音频来源

大雨、海浪、溪流、森林、微风、火车、篝火和咖啡馆使用随 APK 发布的循环
MP3。其余声音使用独立重写的近似算法，不直接复制外部项目实现。

算法音源实现为 `StreamAudioSource`：

- 输出单声道、16-bit PCM WAV 流。
- WAV 头声明两小时总长度，使播放器获得稳定的 `2:00:00` 时长。
- `request(start, end)` 只计算请求字节区间，并分块返回。
- 不创建两小时 PCM 文件，不把整段音频保存在内存或缓存目录。
- 采样由绝对采样位置和固定种子决定，支持播放器的范围请求和重新连接。
- 白、环境底噪采用确定性噪声、分频叠加、滤波近似和低频包络。
- 雷、鸟、虫、翻书、滴答等事件按时间槽和固定种子调度，避免依赖从零开始
  的可变滤波状态。
- 每个流块限制大小并异步让出执行权，避免阻塞 UI。

MP3 声音由专用白噪音播放控制器循环。控制器向界面提供统一的两小时会话
进度，不把 MP3 自身的短循环时长当作模式总时长。

## 播放会话

选择类型后：

1. 停止当前普通音乐或旧白噪音会话。
2. 为该类型解析固定或随机的声音。
3. 建立最长两小时的白噪音会话并立即播放。
4. 将现有睡眠定时设为 120 分钟。
5. 进入白噪音播放页。

沙漏按钮继续按“120 -> 关闭 -> 60 -> 120”的现有循环语义工作；倒计时到期
调用统一播放器暂停。用户手动暂停不会重置剩余倒计时。

前一首和后一首不在同类候选中切换，而是在八个类型间循环切换。切换到
“噪音”固定使用白噪音；切换到其他类型时重新随机该类型候选并重新开始
两小时会话。

白噪音播放页复用现有播放/暂停、音量、锁屏媒体控制和设备按钮分发。普通
音乐与白噪音始终只有一个输入源处于活动状态。

## 页面与过渡

新增功能放在 `lib/features/white_noise/`，按现有工程结构拆分 models、services、
controllers、screens 和 widgets。共享播放能力继续放在已有 core service 中，
不复制播放器状态。

类型列表项显示稳定的类型封面。列表封面和播放页封面共享类型 Hero tag，
复用 `AlbumReflectiveArt` 已有的 Y 轴翻转 flight。点击和滚轮 Select 走同一入口，
确保两种进入方式都有相同的 Hero 过渡和播放结果。

Menu 返回类型列表；再次 Menu 返回主菜单。当前会话继续播放，除非用户暂停、
倒计时结束或启动普通音乐。

## 错误处理

- MP3 资源加载失败时，留在类型列表并显示现有样式的信息对话框。
- 算法流请求参数经过范围裁剪；空范围返回空流。
- 随机解析仅从类型声明的非空候选中选取。
- 页面销毁不终止后台播放；新的白噪音会话负责释放旧音源。

## 验收与测试

- 网易云菜单顺序为“播客、推荐、白噪音、设置”，本地菜单中白噪音位于设置
  上方。
- 白噪音页恰好显示八个类型。
- 噪音始终解析为白噪音；其他类型的结果不会越过自己的候选范围。
- 前一首和后一首在八类间首尾循环，并为新类别重新解析声音。
- 流式音源声明两小时长度，范围请求只返回对应字节且结果可重复。
- 测试大偏移请求，证明算法无需先生成前面的音频。
- 开始会话自动设置 120 分钟，计时结束调用暂停。
- 列表点击与设备 Select 使用相同 Hero tag 进入播放页。
- 白噪音和普通音乐切换后只保留一个活动播放源。
- 运行相关单元测试、Widget 测试、格式化和 `flutter analyze`。

## 非目标

- 不提供白/粉/褐或同类声音的二级选择页。
- 不叠加多个环境声音。
- 不保存随机结果为预设。
- 不生成两小时音频文件。
- 不引入新的音频依赖或 Android 专用 AudioTrack 引擎。
